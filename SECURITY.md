# Security policy

## Supported versions

`veridist` 0.5.0 is the supported public release line.

## Reporting a vulnerability

Use the repository's GitHub Security Advisory reporting flow for a suspected
vulnerability. Include a minimal reproduction, the affected revision, and any
relevant environment details. Do not post an exploitable report in a public
issue before maintainers have had an opportunity to assess it.

The project will acknowledge the report, assess scope and impact, and publish
remediation information when a fix is ready. Do not treat this policy as a
promise of a particular response time or a supported-version guarantee.
